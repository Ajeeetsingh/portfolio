01 — The problem

The answer exists. Nobody can find it.

Every company has the same productivity leak: the answer to "what's our remote work policy?" is already written down, buried in a PDF on a shared drive or in the head of whoever answered it last.

So people ask a colleague, again. Or they ask a general chatbot, which answers confidently without ever having read the handbook. In an enterprise there's a second problem: a naive RAG system will happily retrieve a document the person asking was never allowed to see.

02 — What it does

Ask in plain English. Get an answer you can check.

Cited answers

Each claim links to the exact source page, with the passage highlighted.

Permission-aware

Admins decide which roles can see which documents. Access is enforced before retrieval, and no authorised source means no claim.

Any document

Multi-format ingestion with structure extraction and duplicate detection.

Admin tooling

Manage collections, users and roles from one console.
